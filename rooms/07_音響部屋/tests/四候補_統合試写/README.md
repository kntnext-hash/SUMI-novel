## ファイルと権利の照合

4点とも delivery の納品WAVと試写用WAVのSHA-256をQC記録の値に照合した。ファイル名・尺・ハッシュは [assets.json](assets.json)。

- ベルは13gkopeckakのFreesound 378911。recording_rights.jsonがCC0、delivery/edits_and_qc.jsonが元プレビュー0.809104秒からの1.4秒切出しを記録している。
- 通過音はbeskhuのFreesound 276001、CC0。delivery/remaining_20261119_rights_qc.jsonの録音説明は自転車通過（MiniDisc／Sony MC-907）。10.224秒の録音のうち0.5秒窓の平均振幅が最大の区間は3.5–4.0秒。段差への乗り上げには割り当てていない。
- 公園の風はThimrasのPark Ambiences、台所の流水はbretbernhoftのGeneral Household Sound Effects。delivery/batch_rights_qc.jsonの両方がCC0。いずれも原音2–14秒、300msクロスフェード後の11.7秒ループ。
