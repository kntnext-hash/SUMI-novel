# 向かいの机に水筒を置く音

C06S03の原稿「06_裏門で待ってる.md」95行は、手前と向かいの二つの机に置く動作を一段落に含む。試写差分では story_ch06.rpy 79行を「ほとんど音がしなかった。」で区切った。手前は無音、次に表示する「向かいの机に置いたときは、普通にかたんと鳴った。」で1回だけ、相対音量0.42で再生する。原稿97行に当たるゲーム80行は五月の記憶のため、追加の再生はない。2ページを連結すると原文と一致する。

## 途中復帰と読み直し

同じページへのロードと、前のページから次送りをする操作を別々に検査する。既存の学校チャイムと同様、ロード・巻き戻しで同じ場面を復元するときは打音を重ねない。手前まで戻ったプレイヤーが自分で送り直したときは、向かいの机に置く動作に合わせて、新たな1回を再生する。タイトルから再読を始めても初周の再生履歴は影響しない。

## 権利と音源

qubodup「Put down item」（Freesound #792930）は、温かいお茶の半分入った保温瓶を木の机に置いた実録。底材の記載はない。個別録音のライセンス欄はCC0 1.0。作者プロフィールの一般的なCC BY案内も個別の権利記録に併記した。公開HQ MP3の全長をPCM16に変換した納品で、48 kHz・モノラル・0.1663125秒。SHA-256は25f938ab7f048528fd126069beea7d36e77489a7ec4823380ccd179a82da331c。専用コピーのWAVをこの値と照合した。打音の硬さと最終音量は聴感確認待ち。[録音の出典](https://freesound.org/people/qubodup/sounds/792930/) ／ [取得・変換記録](../../audio/delivery/thermos_rights_qc.json)

## 適用と検査

[統合差分](thermos.patch) は、ゲーム本文の物理行を維持するcall、ADVの対応表、ページ指定の効果音を変更する。採用時はリポジトリ直下でgit apply --checkを行い、パッチとともに07室のaudio/delivery/thermos_set_down.wavをgame/audioへ配置し、配布用クレジットへ出典を追記する。

[再現テスト](qa_thermos.rpy) を専用ゲームのgameへ追加し、qa_thermos_save、qa_thermos_restartの順に、別のWindowsプロセス・同じ専用保存先で実行する。前半では初周の2ページ、Windowsのsoundチャンネルでの再生、次の記憶での発音回数を確認。後半ではページ復帰、戻る、次送り、再読の開始を確認する。[Windows実行ログ](windows_result.txt)
