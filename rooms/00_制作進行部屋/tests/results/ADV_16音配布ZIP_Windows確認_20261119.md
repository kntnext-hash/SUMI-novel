# 16音統合版のWindows配布確認

2026-11-19、Windows 11で kaononaiharu-adv-16sfx-win.zip を新しいフォルダーに展開し、同梱のexeを引数なしで起動した。ZIPのSHA-256は b7bab9ada4a148c20562dc34c3ceb770082badae8e7156f89d4066e166f889c1。配布用チェックサムと一致し、1,728エントリのCRC検査でエラーはなかった。ゲームのaudioフォルダーにWAVを16点確認した。

- 起動後は入力せず、橋のOP映像から橋のタイトルメニューへ自動で移ることを確認した。「オープニング」から再生すると映像に戻り、左クリックでタイトルに戻った。
- 「はじめから」を選ぶと玄関に「澄、お弁当」が表示された。隔離保存先の1ページ2番へ通常セーブし、クリックで次の地の文を表示した。通常ロードの確認画面で「はい」を選ぶと、元の玄関と台詞に戻った。
