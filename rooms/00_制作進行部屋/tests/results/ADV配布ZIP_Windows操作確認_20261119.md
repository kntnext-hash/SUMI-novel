# ADV配布ZIPのWindows操作確認

2026-11-19、Windows 11。配布用の `kaononaiharu-adv-split-win.zip` を専用フォルダーに展開し、同梱の `kaononaiharu.exe` を起動した。

| 操作 | 実画面で確認した結果 |
| --- | --- |
| 起動してOPの終了を待つ | 無彩の教室から屋根と「顔のない春」の題字へ進み、橋のタイトルメニューが表示された。 |
| タイトルの「はじめから」を選ぶ | 白黒の玄関と下部の和紙枠に「澄、お弁当」が表示された。クリックすると台詞が消え、玄関についての地の文が2行で表示された。 |
| 冒頭の台詞を空き枠に保存し、一段進めてからロードする | 1ページ目の2番に保存時刻とサムネイルが表示された。ロード確認で「はい」を選ぶと、玄関と「澄、お弁当」が復元された。 |
| タイトルの「オープニング」で再生し、冒頭の橋の映像を左クリックする | 教室や終端の題字を待たずに再生が終了し、タイトルのメニュー項目が再表示された。 |
| 冒頭の台詞でマウスを中央クリックし、もう一度中央クリックする | 和紙枠と下部のボタンが同時に消え、玄関の靴や床まで見えた。2回目で同じ台詞に戻った。「操作方法」には H キーの案内も表示される。H キーは今回の自動入力では切り替わりを確認できなかった。 |
