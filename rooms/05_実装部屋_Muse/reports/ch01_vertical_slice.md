# 第1章 Ren'Py 縦切りデモ実装計画（REVIEW）

実装担当はMuse。Ren'Py SDK 8.5.3で、朝の橋から章末の局所彩色までを抜粋で再生する。本文・演出の採用判断と本編への統合時期は別途記録する。

| 1　S-101 朝の通学路 | 「橋の継ぎ目を踏んだ。」から最初の呼びかけ直前まで。stage 0で背景・UIを無彩にする。 | 橋と欄干を示す灰色の仮背景と無彩の本文枠。継ぎ目の音源未着時は本文の「かたん」で進行する。 |

## 状態と復元

場面、本文位置、章末キューの経過時間をセーブ・巻き戻し対象とする。色と人物表示はこの値から組み直す。章末直前は無彩、途中では保存した濃度から再開し、完了後は最終濃度を保持する。開始文から即送りした場合は「ほんの少しだった。」の表示と同時に最終状態にし、「まだ、空を見ていられた。」の後、章末を送るまで保持する。スキップ解除時は開始文の前なら無彩、開始文の途中なら表示済みの濃度から再開し、「ほんの少しだった。」以降なら最終状態を保つ。新規開始・回想開始時は開始位置の状態を設定する。セーブの縮小画像はその時点の表示結果から生成する。

## 試験と完了条件

1. 通常送りとスキップで3場面を通す。開始文の前で長く待つ、開始文から即送る、開始文の前・途中・次文でスキップを解除する各操作を試し、青の先出しと滲み直しがないことを確認する。透花の発話で色が出ず、章末では無人の空だけが変わることを確認する。
2. 彩色直前・途中・完了後で別々に保存し、再起動して各スロットをロードする。本文位置、青の濃度、人物表示、サムネイルを保存時と照合する。巻き戻して出会いに戻ると全域無彩になることも確認する。
3. 等倍・縮小で顔の細部を確認し、章末の前後画像を比較して有彩画素が許可マスク内に収まるか調べる。バックログ・回想・ギャラリー・UIプレビューは実装済みの入口から確認し、元絵や参照画像が表示候補に入らないことを確認する。
4. 仮素材での試作完了は、通常送り・スキップ・復元試験を通過し、使用素材の版、結果、未提供素材と未実装の入口を記録した時点とする。本素材への置換後は同じ試験に加え、顔被覆・マスク位置・実音の同期を再検査する。現時点では計画のみで実機試験は未実施。
