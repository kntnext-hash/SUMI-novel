# 長編ADV化｜混在段落の分割案

台詞内の引用は外側の括弧を優先して一まとまりに扱う。C05S07 L18のメッセージ内にある父の「こんなのだったっけ」を現在の父の発話にしない。括弧の有無だけでは声にしない。「言いかけた」「言わず」「だったら」「送ればよかった」の言葉は、本文に即して地の文に残す。

### C01S01 L10

元文には、既出の挨拶の引用と、その場での澄の返事がある。

1. 地の文　きちんと聞こえた「いってらっしゃい」には、返事ができる。
2. 澄　「いってきます」
3. 地の文　そう言って、今度こそ戸を閉めた。

母の挨拶をここでもう一度再生しない。「と言って」は「そう言って」に置き換える小編集案。

### C01S02 L26

1. 地の文　無意識に紙の反対側を見た。透花さんが口の近くで囁く。
2. 透花　「気になってたでしょ」

## 編集判断と保留

回想場面として進行する小一の会話は幼い話者に分ける。反復する幼少期の遊びの要約や、END後の独白の中でさらに昔を振り返る引用は、語り手の地の文に残す案とした。EBS04の当日のパンの場面は澄の声を再演する案を記載したが、透花の独白を通して読ませる演出も可能。演出の統一時に選ぶ。

通信文は送信済みか草稿かまで本文で判定する。C06S06 L9は未送信の草稿、C12S03 L8は書きたくなっただけの書き置き。書かれた文字を扱うT判定は送信済みを意味しない。

話者の表示名は本文時点で分かる範囲の案。声の断片「ちゃ」、複数人の声、繰り返す謝罪を完全な台詞に補わない。間接話法の「〜と聞いた」に新しい台詞を創作しない。

原稿の変更とゲームへの反映は未実施。今回の照合と原文復元検査は分割位置の確認まで。全632断片をこのまま表示文として投入するための資料ではなく、表示用の助詞整理・話者欄の最終確認を伴う編集案。
