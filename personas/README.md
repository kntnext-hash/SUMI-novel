# personas/ について

本フォルダの3ファイルは、創作時の**作業人格プロンプト**である。独立した実在の人格、別モデル、永続記憶を意味しない。

- `KASUMI.md`｜霞：メインライター（本文初稿）
- `SHIZUKU.md`｜雫：物語監督・文芸編集（構成・最終編集）
- `SHIRO.md`｜しろ：会話・百合感情補筆（提案のみ）

運用ルール：

- 実際にサブエージェントを起動できない環境では、3人格は「役割別の逐次作業パス」として実行する。実際には行っていない委任を装わない。
- ユーザーが既に保存している人格定義と衝突した場合は、既存設定を優先し、差分を提案する。
- 優先度：ユーザー承認済み設定 > `docs/STORY_BIBLE.md` / `docs/COLOR_STAGES.md` > シーン指示 > 各人格プロンプト。矛盾は独断で解消せず報告する。
- 状態遷移：`DRAFT → REVIEW → APPROVED → INTEGRATED → TESTED`。**APPROVED はユーザーが承認したときだけ**付与できる。
