# 『顔のない春』画像制作と組み込み

## Codexで用意する画像

「Codex_画像生成一覧.tsv」の各行について、まず FULL を描く。参考画像の左の黒髪ロングが澄、右の栗色でリボンを結んだ子が透花。共通仕様は横1920×1080、和紙に墨線と鮮やかな透明水彩。顔・色を後から戻せるよう全彩原画では表情まで決める。背景だけの行は無人。イベント画は本文の人数・立ち位置・服装に合わせ、画面の下四分の一に台詞窓が重なることを想定する。看板や名札など筋に必要な文字は別レイヤーで日本語を組む。

次に、各行に指定した「初周差分」を、確定した同じFULL画像を入力参照にして編集する。画角、指の位置、時計の針、風の向き、布のしわまで固定。全面を墨と紙の濃淡に戻し、下表で許された箇所にだけ原画の色を戻す。物が画面にない場合は色を足さない。顔の余白は目鼻口・眉など個人が判る線を省き、顎や髪の外形、首の傾きは残す。事故や負傷に見える塗り潰しを避ける。スマホや写真に写った顔にも同じ段階を適用する。

| ファイル末尾 | 初周の許容範囲（当該画面にある物のみ） |
|---|---|
| 0 | 全面墨。全員の顔は余白。 |
| 1A | 電線の間の空から、澄が見つけた範囲の青。 |
| 1B | 空に加え、光の開いた川面の青。 |
| 1C | 上記と、砂糖菓子の鳥の欠けたくちばしの蜜色。 |
| 2 | 上記と、握り直した透花の親指の根元から見える肌。花火と人波は濃淡。 |
| 3 | 上記と、風がほどいた透花の栗色の髪。顔は写真でも余白。 |
| 4 | 透花の顔の形・表情と、本文で見えたところの色。他人の顔、室内の色はまだ抑える。 |
| 5、FULL | 全彩、顔あり。5とFULLは同じ原画を書き出してよい。 |

## Museで表示する位置

「Muse_本文キュー.tsv」のノードを scenario.json の nodes のキーに結合。本文行は各ノード内の lines の先頭を1とする。該当行が画面に出る直前に、初周なら「初周表示」、クリア後に全彩で再読する場合は「再読表示」のPNGへ切り替える。同じ行に二指示あれば後の行が前面。次のキューまで画像を保持し、別ノードへ移るときはそのノードの先頭キューで置き換える。ENDの後に次の本文を自動表示しない。

二周目も三月の選択条件、独白、間の長さは初周と同じ。四月の橋で透花が上げかけて戻す手、九月に気づいてもらった一瞬、十一月に缶が二度鳴る間の顔を、同じ台詞の下で読めるようにする。一月まで初周に透花の表情を見せない。二月の全彩の切替は透花の不在中、「花の形をしたにんじんが、橙色だった。」の行。人物の見分けやすさは、字幕の話者名でも先取りしない。
