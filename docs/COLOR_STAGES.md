# COLOR_STAGES.md｜色彩段階と演出契約

色彩解放の絶対順序：**完全モノクロ・顔なし → 景色 → 肌 → 髪 → 第5章で透花の顔 → 世界全体の彩色**。変更禁止。

## Stage 契約（実装＝Muse へ渡す最低限の契約）

| stage | 背景 | 肌 | 髪 | 透花の顔 | 他人の顔 | 主な対応 |
|---:|---|---|---|---|---|---|
| 0 | 無彩 | 無彩 | 無彩 | 非表示 | 非表示 | 第1章序盤。完全モノクロ |
| 1 | 一部彩色 | 無彩 | 無彩 | 非表示 | 非表示 | 第1章末〜第2章。景色の微彩・淡彩 |
| 2 | 一部彩色 | 彩色開始 | 無彩 | 非表示 | 非表示 | 第3章。指先の肌色 |
| 3 | 一部彩色 | 彩色 | 彩色 | 非表示 | 非表示 | 第4章。髪色 |
| 4 | 彩色拡大 | 彩色 | 彩色 | 初めて表示 | 原則非表示 | 第5章。透花の顔だけ解放 |
| 5 | 全体彩色 | 彩色 | 彩色 | 表示 | 必要に応じ解放 | 第6章（TRUE）。世界全体の彩色 |

## パレット規則

- 初期（stage 0〜1）は赤を含む一切の彩色禁止。最初の色は景色の青（空）の微彩とする。
- 全stageを通じて墨・和紙・余白の質感を維持する。アニメ塗り（フラットなセル塗り）へ切り替えない。色は「塗る」のではなく「滲んで戻る」表現とする。

## シーンメタデータ（全シーン必須）

`scene_id / chapter / title / writer / editor / visual_stage / background_id / characters / face_visibility / status`

- status は `DRAFT → REVIEW → APPROVED → INTEGRATED → TESTED` で管理。APPROVED はユーザーの承認時のみ。

## 漏洩防止（実装・QA共通）

- 背景・肌・髪・顔の領域マスクと演出IDを定義し、段階の前倒しを防ぐ。
- 以下でも先の色や顔を見せない：ロード画面、バックログ、スキップ中、セーブサムネイル、ギャラリー、回想、UIプレビュー。
- 本文側の漏洩も禁止：解放前は地の文で瞳・口元・笑顔などの視覚情報を書かない（`personas/KASUMI.md` の視覚制約を参照）。

## 素材の受け渡し形式（素材担当との契約）

- 背景・CG：1920×1080。立ち絵：透過PNG。
- 段階違いの素材は寸法・位置をピクセル単位で一致させる。
- 形式は「段階ごとの完成絵」または「モノクロ原画＋色彩レイヤー（透過PNG）」のいずれかで統一する。
- ファイル名は英数字、末尾に stage を付ける（例：`bg_station_s0.png`、顔あり素材は `char_touka_face_` 接頭で明確に分離）。
- 全素材は `docs/ASSET_REGISTRY.csv` に登録する。未作成の素材は `PENDING` と記録し、存在を偽らない。
