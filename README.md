# SUMI-novel

幻想百合ビジュアルノベル『顔のない春』の制作リポジトリ。

> 『顔のない春』――きみの色が見えるまで。
> わたしは、まだ、あなたの顔を知らない。

## 作品概要

- ジャンル：文学的幻想百合・心理ドラマ・ビジュアルノベル
- 主人公：澄（すみ）／メインヒロイン：透花（とうか）
- 想定プラットフォーム：Windows（Steam）先行、モバイル展開検討
- 企画段階：コンセプト確立・シナリオ構想（構想段階）
- 画像素材・シナリオ：制作者側で用意
- 制作基盤：Ren'Py（SDK 8.5.3 を別環境に導入・検証済み）

コンセプト：過去のトラウマによって世界の色と人間の顔を認識できなくなった少女が、一人の少女と出会い、景色→肌→髪→顔の順に色彩と表情を取り戻していく物語。「顔が見えること」を恋愛表現の最大の到達点にする。
